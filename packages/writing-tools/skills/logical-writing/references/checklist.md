# 퇴고 체크리스트

최종 검토나 검토 요청 때 읽는다. 규칙의 기준은 [SKILL.md](../SKILL.md)이며, 아래 질문은 그 규칙의 적용을 돕는다. 결함을 찾으면 위치·독자에게 미치는 영향·수정 방향을 함께 기록한다. 체크 표시만으로 검토 결과를 대신하지 않는다.

## 구조와 포함

- 독자와 판단 기준이 명확한가? 필요한 배경을 내부 맥락 없이 이해할 수 있는가?
- 결론이 앞에 있고 각 단락의 역할을 한 줄로 설명할 수 있는가?
- 논점을 나눈 이유가 타당한가? 겹침·누락·분류 밖의 사례를 처리했는가?
- 각 문장이 뒤의 설명이나 독자의 판단에 필요한가?
- 판단과 무관한 절차 확인·방어적 단서·시행착오·내부 사정을 뺐는가? 중요한 한계는 남겼는가?
- 상세 절차와 표를 부록으로 보내도 본문의 판단 근거가 유지되는가?

## 논리와 비교

- 관측 → 진단 → 가설·행동 → 결과 → 다음 판단이 연결되는가? 제안에는 검증 계획이 있는가?
- 관측을 어떻게 알았는가? 다른 원인 후보와 구분할 근거가 있는가?
- 비교의 기준 대상·바꾼 조건·고정한 조건·판단 기준이 보이는가? 선택한 조건만이 아니라 조건별 결과를 함께 보여 주는가?
- 결과의 크기뿐 아니라 의미를 설명했는가? 관측만으로 원인을 단정하지 않았는가?
- 사후 분석과 최초 설계를 구분했는가? 서로 다른 가설의 결론을 합치지 않았는가?
- 처음 쓰는 개념을 소개했는가? 앞의 동기와 뒤의 행동 사이에 논리적 도약이 없는가?
- 나열을 넘어 핵심 명제와 그 명제가 바꾸는 판단을 제시했는가? 반례나 기존 산출물의 중요한 통찰을 놓치지 않았는가?

## 표현과 근거

- 표준 용어를 확인하고 정의·표기를 통일했는가? 의미가 불명확한 자작 비유를 없앴는가?
- 수치의 측정 대상·분자·분모·단위·조건이 명확한가? 다른 집합을 부분과 전체로 오해하게 하지 않는가?
- 지시어의 실체와 문장의 주어·행동이 보이는가? 한 문장에 서로 다른 내용을 욱여넣지 않았는가?
- 선택과 분석에 독자가 검토할 수 있는 근거, 방법의 타당성, 수행 조건이 있는가?
- 확인된 사실·사후 근거·추정·근거 없음을 구분했는가? 출처를 직접 열고 원자료 및 이후 정정과 대조했는가? 여럿이 모은 근거라면 조사하지 않은 검토자가 대조했는가?
- 맥락 없는 독자가 결론과 근거를 설명할 수 있는가? 그 독자가 추측한 부분을 수정했는가?
